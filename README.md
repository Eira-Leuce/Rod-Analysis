# Rod-Analysis
Практическое задание дисциплины "Конечноэлементные программные комплексы", расчет НДС стержня аналитическим методом и МКЭ.
## Стек
- **Python:** быстрый и удобный язык для математических рассчетов. 
- **NumPy:** используется для создания матрицы жесткости, решения СЛАУ и работы с массивами.
- **SciPy:** используется для интегрирования.
- **Matplotlib:** используется для построение эпюр продольных сил, напряжений и перемещений.
### Листинг 2pz
**Аналитическое решение**
* Расчет реакций опор и уравнений статики.
* Вычисление эпюр с использованием метода сечений.
* Интегрирование перемещений по длине стержня.
### Листинг 2pzmke
**Метод Конечных Элементов**
* Программная реализация алгоритма МКЭ.
* Поддержка линейных и кубических конечных элементов.
* Сравнение сеток с разным количеством элементов.
